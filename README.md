Plugin written in Python. It is laggy with ELF files bigger than 100 KB (Binja might crash).
For bugs/issues, open an issue on my [repo](https://github.com/noah0x1/LoongArch64-Binary-Ninja-Binja-Plug-in).

Parts of this plugin were written with AI. In version 0.2.0 I will rewrite those parts by hand.

Right now it only supports Linux (LoongArch64 is mainly used with Linux), but macOS support is planned (Windows maybe) (It COULD work on Mac and Windows, but I never tested it. If someone tests it for me, then I'll know it works on other platforms. It's just Python, so normally it should work, but we never know.).

I also want to port it to C++ later so it runs much faster.
I started with Python so I can keep learning with Python, since I've never really coded in high-level programming languages before.

Please don't use version 0.1.0 for commercial work. It is only a \"beta\" right now.

I will keep updating it for a long time. This is one of my main Binja plugins I wanted to make (another one could be coming, but then give me some time ;-) ).
